# Héctor Tu Entrenador Personal

Gestión de clientes de entrenamiento personal: clientes, planes, dietas, pagos, deudas, horarios y progreso.

App web instalable (PWA). Funciona en el celular, la computadora y el navegador, y también sin conexión.
Los datos se guardan en cada dispositivo; usa Ajustes → Exportar respaldo para guardar una copia.
